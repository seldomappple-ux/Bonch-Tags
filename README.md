# Bonch Tags

简洁明快的零件收纳小标签快速排版与打印基座（本地浏览器运行，零额外打印驱动）。

## 核心特性

- **四层解耦基座**：图标库 / 零件库 / 尺寸与样式 / 纸张与打印完全分离，后续扩展新款式或切换打印机无需重做。
- **两档常用黑白上下双格尺寸**（支持随时自定义 mm）：
  - **小号 `10 × 13 mm`**：上格图标 + 下格简短规格（如 `M2`、`CH224K`）
  - **中号 `15 × 20 mm`**：上格图标 + 下格多行详细说明（如 `MPU6050 / 6轴IMU | I2C`）
- **热升华 / 热敏专属预热引导条**：支持在出纸方向前端或前后两端自动添加预热黑条，解决打印头起步温度不足导致首排线条发虚的问题。
- **内置 SVG + AI 画图规范闭环**：内置常用电子/机械元件黑白矢量图标，一键复制 AI 画图标规范 Prompt，粘贴 SVG 代码即可自动清洗入库。
- **拖拽/点击即排版，直接点字改参数**：同一个图标可无限复用，直接点击标签文字修改不同规格。
- **本地数据安全 & 历史打印单**：本地自动保存、支持历史打印单回溯重打、支持一键导出/恢复 `.json` 全量备份包。

## 本地运行

```bash
npm install
npm run dev
```

构建生产静态包（可直接分发给他人使用）：

```bash
npm run build
```
